Layer 2 — Matrix × Vector, packed to the instruction

No generic GEMV algorithm is invented here. One destination i32 lane is one matrix row. The vector chunk is repeated in B so a single VNNI instruction advances multiple rows by 4 columns (byte family) or 2 columns (word family).

8 rows × 4 K  / instruction
