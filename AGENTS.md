# Buildin ownership

Only the user can explicitly promote a specific Blueprint to a buildin. Do not invent new buildins, place new app subsystems at the TRUEOS-Buildins root, or add entries to buildins.json without that explicit decision. Tentative language such as "perhaps" is not promotion approval.

IDEdit development tools (including Codex CLI, MCP helpers, database tools, and idedit_htmlbuild_srv) belong to the on-demand Blueprint ecosystem. Edit and Hull being buildins does not make IDEdit subsystems buildins.
